# Security

This tool opens a sealed archive and prints its secrets, so its correctness matters.

To report a vulnerability in this code, email **contact@ifynx.com** with details and steps to
reproduce. Please do not open a public issue for it. We aim to reply within 3 business days.

The files in `Tests/RecoverKitTests/Vectors` (an archive, three shares and a password export) are
**deliberately public** test data made of invented items. Please do not report them as leaked
secrets.
